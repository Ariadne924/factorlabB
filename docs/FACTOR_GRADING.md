# 因子分级与轮动

项目保留全部正式候选因子，不因当前样本表现较低而删除。`scripts/grade_factors.py` 根据已有
报告生成四级研究优先级：

- A：当前适配度高，优先做跨口径与锁定样本验证；
- B：当前适配度中等，继续观察并可进入候选组合；
- C：当前适配度较低，保留但降低本轮研究优先级；
- D：数据不足或前视检查未通过，等待补数或修复。

评分综合当前 RankIC、ICIR、方向一致性、分层单调性、FDR、样本量、口径覆盖和 ML 训练折
稳定性。评级不会把测试期策略收益反馈给同一轮训练。每次运行会写入
`reports/factor_grades/latest.json` 和带时间戳的历史快照，用于观察升降级。

高评级不等于已验证 Alpha；低评级也不代表因子永久无效。默认每 7 天轮动一次。
