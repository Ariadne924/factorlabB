# Return Momentum

## 定义与经济含义

- 定义：`close_t / close_{t-window} - 1`。
- 经济含义：刻画历史收益延续；正向仅是待检验假设。

## 数据依赖与参数

- 数据依赖：Silver `close`；默认 `window=12`。
- 时间对齐：只读取 t 与更早收盘价。
