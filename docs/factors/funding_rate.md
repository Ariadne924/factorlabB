# Funding Rate

## 定义与经济含义

- 定义：最近 window 次已公布资金费率的历史均值。
- 经济含义：永续多空拥挤与持仓成本代理；正负方向需实证。

## 数据依赖与参数

- 数据依赖：永续 `funding_rate`；默认 `window=3`。
- 时间对齐：以公布/结算时间向后合并到 K 线，严禁未来回填；现货与永续不可混用。

## 评估结果

- IC / RankIC / ICIR、IC decay、分层测试、换手率：当前无可引用真实结果。
- 前视检查：点时合并 + 截断重算，状态见 JSON。
- 成本假设：交易成本单边 0.15%；资金费本身需在策略 PnL 中另计。

## 局限

结算频率、交易所规则和极端费率制度会变化；没有六个月 OOS，不能称为已验证 alpha。
