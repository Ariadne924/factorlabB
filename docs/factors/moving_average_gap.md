# Moving Average Gap

## 定义与经济含义

- 定义：`close_t / mean(close_{t-window+1:t}) - 1`。
- 经济含义：描述价格相对历史趋势中枢的偏离。

## 数据依赖与参数

- 数据依赖：Silver `close`；默认 `window=20`。
- 时间对齐：rolling 窗口右端为当前行。

## 评估结果

- IC / RankIC / ICIR、IC decay、分层测试、换手率：当前无可引用报告数值。
- 前视检查：一键脚本执行截断不变性检查。
- 成本假设：手续费 0.10% + 滑点 0.05%（单边）。

## 局限

趋势与反转解释取决于持有期；短样本结果不构成验证，六个月 OOS 未完成。
