# Realized Volatility

## 定义与经济含义

- 定义：对数收益在 window 内的滚动样本标准差。
- 经济含义：历史价格风险代理；风险溢价方向并非预设结论。

## 数据依赖与参数

- 数据依赖：Silver `close`；默认 `window=20`，未年化。
- 时间对齐：rolling 窗口不包含未来收益。

## 评估结果

- IC / RankIC / ICIR、IC decay、分层测试、换手率：仓库无真实样本，留空。
- 前视检查：由研究脚本留痕；成本假设为单边 0.15% 总成本。

## 局限

跨频率不可直接比较，极端行情估计不稳；六个月 OOS 未完成。
