# RSI

## 定义与经济含义

- 定义：window 内平均上涨幅度相对平均下跌幅度转换到 0–100。
- 经济含义：衡量近期涨跌力量不对称；方向需由实证决定。

## 数据依赖与参数

- 数据依赖：Silver `close`；默认 `window=14`。
- 时间对齐：差分与滚动均值均只含历史。

## 评估结果

- IC / RankIC / ICIR、IC decay、分层测试、换手率：暂无真实数据结果。
- 前视检查：结果写入单因子报告；成本假设为单边 0.10% 手续费 + 0.05% 滑点。

## 局限

单边趋势中可能长期处于极值；没有锁定六个月 OOS，不得宣称已验证 alpha。
