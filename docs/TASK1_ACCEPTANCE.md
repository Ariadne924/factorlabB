# Task 1 验收状态

本文件按任务卡区分工程实现、测试覆盖和真实实证，避免把候选因子描述为已验证 alpha。

## 已实现

- Binance REST/WS、统一 Schema、UTC、Bronze/Silver/Gold、增量更新、异常 flag 与数据质量报告。
- Binance K 线、聚合成交、盘口、Funding、OI、Basis；官方月度 K 线归档及 checksum 校验。
- 第二交易所 OKX 的最小公共客户端，覆盖统一 K 线、成交、盘口和 Funding 接口。
- 40 个以上候选因子、统一 registry、数字资产特有因子与至少 8 张说明卡。
- IC、RankIC、ICIR、IC decay、分层、换手率、滚动 IC、相关性、成本敏感性与 BH-FDR。
- 截断未来重算的自动前视检查，以及独立 `reports/lookahead_report.json` 门禁留痕。
- 单因子报告、因子总览 Streamlit、一键研究入口。

## 仍需真实数据才能验收

- 多资产、多频率真实结果目前不完整；仓库中的短样本结果不能称为稳定 alpha。
- 长历史 OI/Basis 受交易所公开保留期限制，需要合法可靠的归档源或持续自建归档。
- 六个月 OOS 尚未执行。先用 `scripts/lock_oos.py` 锁定区间，开发期不得查看；最终提交前只运行一次。
- “干净环境一次跑通”需在交付机 Python 3.12 环境重新执行完整质量门禁和研究脚本。
