# 单资产多因子时序策略

本模块把正式 time-series factor registry 与交互回测连接起来，用于回答“同一个币种在什么
时间持有多头、空头或空仓”。它与 panel strategy 的“同一时点选择哪些币种”是两个不同问题。

## 执行口径

- 每个因子仅使用当时及以前的数据计算；
- 因子采用滚动窗口 z-score，不使用全样本均值和标准差；
- 多因子按用户权重合成，只对当时非空的因子重新归一化；
- `long_short` 根据正负阈值产生 `+1/0/-1`，`long_only` 产生 `1/0`；
- 目标仓位强制 `shift(1)`，信号至少延后一根 K 线执行；
- 收益同时输出成本前和成本后结果，并报告换手、成本拖累、回撤、胜率和活跃敞口。

## ML 预设

`build_ml_strategy_preset` 只读取 walk-forward 训练折生成的推荐列表，把正式因子、方向、参数
变体和推荐分数转换为归一化策略预设。测试折收益不会参与预设权重生成。

该预设只减少用户手工录入，不代表最优权重，也不代表完成锁定六个月 OOS。

## 前端入口

Streamlit“策略研究”入口中的“单币种择时”支持：

- 单币种与频率选择；
- 多个正式因子及方向、权重；
- 30/90/180 天、全部或自定义时间区间；
- 标准化窗口、开仓阈值、调仓间隔、手续费和滑点；
- 净收益、成本前收益、Bar Sharpe、最大回撤、换手率、胜率及逐期结果；
- 从 ML Factor Mining 的前五个训练折推荐一键带入候选配置。

所有输出都是当前样本研究结果，不能描述为已验证 Alpha 或可直接实盘的执行系统。

## 稳健性与策略快照

基础回测完成后，页面可直接生成：

- 对同一 gross return 和 turnover 路径进行不同单边成本重定价；
- UTC 自然月收益、月内回撤、月内换手和正收益月份占比；
- 固定 K 线窗口的滚动收益、原始 bar Sharpe 与窗口内最大回撤；
- 与完全相同对齐区间的 Buy & Hold 比较；
- 阈值、调仓间隔及标准化窗口的小型参数邻域检验。

参数邻域只用于检查结果是否对微小设定变化敏感，不自动选择最优参数。保存按钮会把当前配置、
结果和稳健性诊断作为不可变 JSON 快照写入 `reports/strategy_snapshots/`，前端可比较多个快照；
该目录默认不上传 GitHub。

## 市场状态与策略 Walk-Forward

策略稳健性实验室还包含两项更严格的诊断：

- 市场状态使用过去价格趋势、过去波动率和滚动历史波动中位数，划分牛市、熊市、震荡及
  高/低波动状态。每根收益 K 线使用的状态标签再整体滞后一根 K 线，因此这里只做因果归因，
  不把事后状态当成策略信号；
- 策略 Walk-Forward 在每一折的扩展训练集内比较小型参数邻域，保留 embargo，冻结训练期
  选出的阈值、调仓间隔和标准化窗口，然后只汇总随后不重叠测试区间的净收益。

Walk-Forward 输出逐折训练区间、测试区间、入选参数、训练目标、所有候选训练分数和连续 OOS
权益路径。它改善了同样本参数扰动的证据质量，但仍是当前短样本的滚动检验，不能替代尚未开启
的锁定六个月 OOS 验收，也不能把短样本表现称为已验证 Alpha。
