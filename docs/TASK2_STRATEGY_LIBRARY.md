# Task 2 策略库与验收口径

## 当前实现

`strategies/` 使用统一的 `generate_target(frame) -> Series` 接口。策略只生成目标敞口，
成交、成本、资金费率、杠杆和风控统一交给回测层，避免策略私自计算收益。

当前四类模板：

- 趋势跟踪：快慢均线方向。
- 网格交易：围绕滚动锚点分层调整库存。
- 统计套利：两资产滚动对冲价差 z-score。
- 均值回归：价格偏离滚动均值后的反向敞口。

所有目标在 `t` 形成，最早从 `t → t+1` 收益开始生效。模板是可解释研究基线，不代表这些
参数或策略已经有效。

## 双回测口径

`strategies/backtest.py` 同时提供：

- 向量化引擎：快速参数和阈值扫描。
- 逐事件引擎：路径依赖风控和触发记录。
- 一致性门禁：关闭路径依赖风控后，逐期净收益最大绝对误差默认不得超过 `1e-12`。

成本包含单边手续费、滑点和 Funding Rate；持仓收益按配置杠杆放大。路径依赖风险只在
逐事件引擎执行，因此不把风控后的差异错误描述为两引擎不一致。

## 风控

`trading/risk.py` 已实现并可执行：

- 单笔止损
- 最大回撤熔断
- 单标的仓位上限
- 杠杆上限
- 异常行情熔断（极端涨跌、点差、数据陈旧）

每次触发都写入结果的 `risk_events`。确定性压力测试覆盖全部规则；自然历史是否触发则由
`reports/task2/strategy_acceptance.json` 如实记录，未触发的规则不会冒充已在真实样本触发。

## 阈值研究

`strategies/threshold_research.py` 输出阈值与收益、换手、回撤、胜率的关系表，并按照
`收益 - 0.5×|回撤| - 0.1×换手` 构造研究评分。推荐的是围绕最佳点的连续近优平台，而非单一
尖峰；同时分别统计上行、下行、震荡状态的候选阈值及漂移情况。

运行基础验收：

```bash
python scripts/run_task2_acceptance.py
```

该报告仍是当前样本研究，不等于最后 6 个月锁定 OOS，也不代表已验证 Alpha。
